BOUNCE QUEST - Java 2D Platform Game

Requirements:
- Java JDK 17 or newer (tested with JDK 21)
- No external libraries needed

Run on Windows:
1. Open this folder in File Explorer.
2. Click the address bar, type cmd, and press Enter.
3. Run:
   javac BounceQuest.java
   java BounceQuest

Controls:
- A / Left Arrow: move left
- D / Right Arrow: move right
- Space / W / Up Arrow: jump
- Enter: start from title screen
- R: restart

This is an original small Java game inspired by classic bouncing-ball platform games.
